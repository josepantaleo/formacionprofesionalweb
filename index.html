JavaScript

Fundamentos de JavaScript para crear páginas web interactivas.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar comportamiento e interactividad a nuestras páginas web. Es un lenguaje interpretado, versátil y muy popular en el desarrollo web moderno.

¿Por qué aprender JavaScript?

JavaScript te permite:

  • Crear efectos visuales y animaciones
  • Validar formularios antes de enviarlos
  • Responder a acciones del usuario
  • Modificar el contenido de la página dinámicamente
  • Comunicarse con servidores sin recargar la página

🧪 ¿Cómo probar los códigos?

Tenés 2 formas de probar los ejemplos de JavaScript:

  1. Crear dos archivos en Visual Studio Code: prueba.html y prueba.js.
  2. Ejecutar los ejemplos directamente desde este sitio web, sin necesidad de crear los archivos manualmente.
Recomendación

Si estás aprendiendo programación, probá primero los ejemplos en el sitio y luego creá tus propios archivos prueba.html y prueba.js para practicar.

Variables

Las variables sirven para guardar información que podemos utilizar posteriormente.

¿Qué es una variable?

Una variable es un contenedor que guarda un valor. Podemos compararlo con una caja en la que guardamos algo. La caja tiene un nombre y adentro hay un valor. 

let nombre = "Juan";
let edad = 20;
let altura = 1.75;

console.log(nombre);
console.log(edad);
console.log(altura);

Palabras clave para variables

  • let: Variable que puede cambiar.
  • const: Variable que no puede cambiar.
  • var: Variable antigua. Se recomienda utilizar let o const. 
let ciudad = "Córdoba";

// puede cambiar
ciudad = "Villa Dolores";

const PI = 3.14159;

// NO puede cambiar


const persona = {
    nombre: "Ana",
    edad: 25
};

persona.edad = 26;

console.log(persona);
💡 Recordá

Usa const por defecto. Solo usa let cuando necesites cambiar el valor de la variable.

Operadores

Los operadores permiten realizar operaciones matemáticas y comparaciones.

Operadores Aritméticos

Se utilizan para realizar operaciones matemáticas.

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** 2);

Operadores de Comparación

Comparan valores y devuelven true o false. 

console.log(10 > 5);
console.log(10 < 5);
console.log(10 >= 10);
console.log(10 <= 5);
console.log(10 === "10");
console.log(10 !== "10");
Usá igualdad estricta

Preferí === y !==. Además del valor, comparan el tipo de dato y evitan conversiones automáticas difíciles de detectar.

Operadores Lógicos

Combinan condiciones booleanas.

const edad = 25;
const tieneDocumento = true;

// AND
console.log(edad >= 18 && tieneDocumento);

// OR
console.log(edad < 18 || tieneDocumento);

// NOT
console.log(!tieneDocumento);

Condicionales

Los condicionales permiten ejecutar código dependiendo de una condición.

if / else

Si la condición es verdadera se ejecuta un bloque.

const edad = 20;

if (edad >= 18) {

    console.log("Sos mayor de edad");

} else {

    console.log("Sos menor de edad");

}

else if

Permite trabajar con múltiples condiciones.

const calificacion = 8;

if (calificacion >= 9) {

    console.log("Excelente");

} else if (calificacion >= 7) {

    console.log("Bueno");

} else if (calificacion >= 5) {

    console.log("Aprobado");

} else {

    console.log("Desaprobado");

}

switch

Permite comparar un valor con diferentes casos.

const dia = 3;

let nombreDia;

switch (dia) {

    case 1:
        nombreDia = "Lunes";
        break;

    case 2:
        nombreDia = "Martes";
        break;

    case 3:
        nombreDia = "Miércoles";
        break;

    default:
        nombreDia = "Día inválido";
}

console.log(nombreDia);

Funciones en JavaScript

Una función es un bloque de código que podemos crear una vez y reutilizar todas las veces que necesitemos.

Las funciones permiten organizar mejor nuestros programas, evitar repetir código y dividir un problema grande en partes más pequeñas.

¿Qué es una función?

Podemos imaginar una función como una pequeña máquina: recibe datos, realiza una tarea y, si es necesario, devuelve un resultado. 

Datos
   ↓
Función
   ↓
Proceso
   ↓
Resultado

Crear una función

Para crear una función podemos utilizar la palabra function. 

function saludar() {

    console.log("Hola mundo");

}

saludar();

La función se ejecuta cuando escribimos su nombre seguido de paréntesis: saludar().

Funciones con parámetros

Una función puede recibir información mediante parámetros.

Los parámetros funcionan como variables que reciben los datos enviados cuando llamamos a la función. 

function saludar(nombre) {

    console.log("Hola " + nombre);

}

saludar("Juan");
saludar("María");
saludar("Pedro");

En este ejemplo, nombre es el parámetro. Los valores "Juan", "María" y "Pedro" son los argumentos.

Parámetros y argumentos

Es importante diferenciar estos dos conceptos:

  • Parámetro: variable definida en la función.
  • Argumento: valor que enviamos a la función. 
function sumar(a, b) {

    return a + b;

}

sumar(10, 5);

En este ejemplo:

  • a y b son parámetros.
  • 10 y 5 son argumentos.

Devolver un resultado con return

La palabra return permite devolver un valor desde una función. 

function sumar(a, b) {

    return a + b;

}

const resultado = sumar(10, 5);

console.log(resultado);

El resultado de la función es 15.

Podemos guardar el resultado de una función en una variable:

const resultado = sumar(20, 30);

console.log(resultado);

Funciones para realizar operaciones

Podemos crear funciones para realizar diferentes operaciones matemáticas. 

function sumar(a, b) {
    return a + b;
}

function restar(a, b) {
    return a - b;
}

function multiplicar(a, b) {
    return a * b;
}

function dividir(a, b) {
    return a / b;
}

console.log(sumar(10, 5));
console.log(restar(10, 5));
console.log(multiplicar(10, 5));
console.log(dividir(10, 5));

Funciones con condiciones

Una función también puede utilizar estructuras if, else y otras instrucciones de JavaScript. 

function dividir(a, b) {

    if (b === 0) {

        return "No se puede dividir por cero";

    }

    return a / b;
}

console.log(dividir(10, 2));

console.log(dividir(10, 0));

Ejemplo: encontrar el número mayor

Podemos crear una función que reciba tres números y devuelva cuál es el mayor. 

function mayorDeTres(a, b, c) {

    if (a > b && a > c) {

        return a;

    }

    if (b > a && b > c) {

        return b;

    }

    return c;
}

console.log(mayorDeTres(10, 25, 15));

Parámetros con valores predeterminados

Podemos establecer un valor que se utilizará cuando no enviemos un argumento. 

function saludar(nombre = "Amigo") {

    console.log(`Hola, ${nombre}!`);

}

saludar();

saludar("Juan");

La primera llamada utiliza el valor predeterminado "Amigo".

Funciones flecha

JavaScript también permite crear funciones utilizando una sintaxis más corta llamada función flecha. 

const multiplicar = (a, b) => {

    return a * b;

};

console.log(multiplicar(3, 4));

Funciones flecha en versión corta

Cuando una función solamente necesita devolver una expresión, podemos escribirla de una manera más sencilla. 

const sumar = (a, b) => a + b;

const restar = (a, b) => a - b;

const multiplicar = (a, b) => a * b;

console.log(sumar(10, 5));

console.log(restar(10, 3));

console.log(multiplicar(4, 5));

Funciones con un solo parámetro

Cuando una función flecha tiene un solo parámetro, podemos escribirla sin paréntesis. 

const doble = numero => numero * 2;

console.log(doble(5));

console.log(doble(10));

Funciones que realizan acciones

No todas las funciones necesitan devolver un valor. Algunas simplemente realizan una acción. 

function mostrarMensaje(mensaje) {

    console.log(mensaje);

}

mostrarMensaje("Bienvenido al curso de JavaScript");

Ejemplo: calcular un promedio

Podemos crear una función para resolver un problema específico, como calcular el promedio de tres números. 

function calcularPromedio(n1, n2, n3) {

    return (n1 + n2 + n3) / 3;

}

const promedio = calcularPromedio(8, 9, 10);

console.log("Promedio:", promedio);

Una función puede utilizar otra función

Podemos combinar funciones para construir soluciones más grandes a partir de pequeñas partes. 

function sumar(a, b) {

    return a + b;

}

function duplicar(numero) {

    return numero * 2;

}

const resultado = sumar(10, 5);

console.log(duplicar(resultado));

Arrays en JavaScript

Los arrays permiten guardar varios valores dentro de una misma variable.

Son ideales para trabajar con listas de datos como nombres, frutas, números, notas, jugadores, productos y mucho más.

¿Qué es un Array?

Un array es una estructura que permite almacenar varios elementos de forma ordenada.

Cada elemento ocupa una posición llamada índice. 

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

console.log(frutas);

Índices

En JavaScript, los índices comienzan en 0. 

Índice:    0          1          2
           ↓          ↓          ↓
Frutas:  Manzana    Banana    Naranja
const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

console.log(frutas[0]);
console.log(frutas[1]);
console.log(frutas[2]);

Modificar elementos

Podemos cambiar un elemento utilizando su índice.

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

frutas[1] = "Pera";

console.log(frutas);

Conocer la cantidad de elementos

La propiedad length nos indica cuántos elementos contiene el array. 

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

console.log(frutas.length);

Obtener el último elemento

Podemos obtener el último elemento utilizando length - 1. 

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

console.log(frutas[frutas.length - 1]);

Agregar elementos con push()

push() agrega uno o más elementos al final del array. 

const frutas = [
    "Manzana",
    "Banana"
];

frutas.push("Naranja");

console.log(frutas);

Eliminar elementos con pop()

pop() elimina el último elemento.

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

frutas.pop();

console.log(frutas);

Agregar al principio con unshift()

unshift() agrega elementos al comienzo del array. 

const frutas = [
    "Banana",
    "Naranja"
];

frutas.unshift("Manzana");

console.log(frutas);

Eliminar el primer elemento con shift()

shift() elimina el primer elemento del array.

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

frutas.shift();

console.log(frutas);

Recorrer un array

Podemos utilizar un bucle for para recorrer todos los elementos. 

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

for (let i = 0; i < frutas.length; i++) {

    console.log(frutas[i]);

}

Recorrer con for...of

for...of permite recorrer directamente los valores del array. 

const frutas = [
    "Manzana",
    "Banana",
    "Naranja"
];

for (const fruta of frutas) {

    console.log(fruta);

}

Bucles

Los bucles permiten repetir una tarea varias veces sin tener que escribir el mismo código nuevamente.

Son fundamentales para recorrer arrays, procesar datos, realizar cálculos y repetir instrucciones.

¿Qué es un bucle?

Un bucle repite un bloque de código mientras se cumpla una determinada condición. 

Inicio
   ↓
¿Se cumple la condición?
   ↓
  Sí
   ↓
Ejecutar código
   ↓
Actualizar
   ↓
Volver a comprobar
   ↓
  No
   ↓
Fin

1. Bucle for

El bucle for se utiliza principalmente cuando sabemos cuántas veces queremos repetir una tarea. 

for (let i = 1; i <= 5; i++) {

    console.log("Vuelta:", i);

}

¿Cómo funciona el for?

El for tiene tres partes:

for (inicio; condición; actualización) {

    // código

}
  • Inicio: se crea el contador.
  • Condición: determina si continúa.
  • Actualización: modifica el contador.

Contador

Una variable contador permite controlar las vueltas que realiza el bucle. 

for (let i = 1; i <= 10; i++) {

    console.log(i);

}

Contador descendente

También podemos contar hacia atrás utilizando el operador --. 

for (let i = 10; i >= 1; i--) {

    console.log(i);

}

Contar de dos en dos

Podemos modificar el contador utilizando otros valores.

for (let i = 0; i <= 20; i += 2) {

    console.log(i);

}

2. Bucle while

El bucle while repite una tarea mientras una condición sea verdadera. 

let contador = 1;

while (contador <= 5) {

    console.log(contador);

    contador++;

}

⚠️ Cuidado con los bucles infinitos

Es muy importante modificar la variable utilizada en la condición.

Si la condición nunca deja de ser verdadera, podemos crear un bucle infinito. 

let contador = 1;

while (contador <= 5) {

    console.log(contador);

    contador++;

}

3. Bucle do...while

El do...while ejecuta el código al menos una vez y después comprueba la condición. 

let contador = 1;

do {

    console.log(contador);

    contador++;

} while (contador <= 5);

while vs do...while

En while, primero se comprueba la condición.

En do...while, primero se ejecuta el código y después se comprueba la condición.

4. Recorrer arrays con for

Una de las aplicaciones más importantes de los bucles es recorrer todos los elementos de un array. 

const nombres = [
    "Ana",
    "Luis",
    "Sofía"
];

for (let i = 0; i < nombres.length; i++) {

    console.log(nombres[i]);

}

5. for...of

for...of permite recorrer directamente los valores de un array. 

const nombres = [
    "Ana",
    "Luis",

7. Acumuladores

El programa calcula:

8. break

for (let i = 1; i <= 10; i++) {

9. continue

continue permite saltar una vuelta del bucle y continuar con la siguiente. 

for (let i = 1; i <= 10; i++) {

Arrays avanzados

En esta clase vamos a trabajar con arrays de forma profesional: transformar datos, buscar información, filtrar resultados, ordenar, calcular valores, combinar métodos y trabajar con arrays de objetos.

🎯 Objetivos

  • Comprender cómo procesar arrays sin modificar accidentalmente el original.
  • Utilizar map(), filter(), find() y reduce().
  • Usar some() y every() para realizar comprobaciones.
  • Ordenar arrays correctamente con sort().
  • Combinar varios métodos en una misma operación.
  • Procesar arrays de objetos, una situación muy habitual en aplicaciones reales.

🧠 ¿Qué significa trabajar un array de forma avanzada?

Un array avanzado no significa solamente tener muchos elementos. Significa poder analizar, transformar, buscar, seleccionar y resumir información utilizando métodos de JavaScript.

Por ejemplo, una aplicación escolar podría tener un array con todos los estudiantes y obtener solamente los aprobados, calcular el promedio, buscar un estudiante o contar cuántos tienen una determinada nota.

1️⃣ map() — Transformar elementos

map() recorre todos los elementos y devuelve un nuevo array con el resultado de la transformación. 

const numeros = [1, 2, 3, 4, 5];

const dobles = numeros.map(numero => numero * 2);

console.log(numeros);
console.log(dobles);
💡 Recordá

map() tiene la misma cantidad de elementos que el array original. Lo que cambia es el valor de cada elemento.

2️⃣ filter() — Seleccionar elementos

filter() crea un nuevo array solamente con los elementos que cumplen una condición. 

const edades = [12, 15, 18, 21, 14, 25];

const mayores = edades.filter(edad => edad >= 18);

console.log(mayores);

3️⃣ find() — Encontrar un elemento

find() devuelve el primer elemento que cumple la condición. Si no encuentra ninguno, devuelve undefined. 

const numeros = [5, 8, 12, 20, 30];

const encontrado = numeros.find(numero => numero > 10);

console.log(encontrado);

4️⃣ findIndex() — Buscar la posición

Es parecido a find(), pero devuelve la posición del primer elemento que cumple la condición. Si no existe, devuelve -1. 

const nombres = ["Ana", "Juan", "Martín", "Lucía"];

const posicion = nombres.findIndex(nombre => nombre === "Martín");

console.log(posicion);

5️⃣ reduce() — Obtener un único resultado

reduce() permite recorrer un array y convertir todos sus valores en un único resultado: una suma, un promedio, un contador, un objeto, etc. 

const notas = [7, 8, 10, 6];

const suma = notas.reduce(
  (acumulador, nota) => acumulador + nota,
  0
);

const promedio = suma / notas.length;

console.log("Suma:", suma);
console.log("Promedio:", promedio);

6️⃣ some() — ¿Al menos uno cumple?

Devuelve true si por lo menos un elemento cumple la condición. 

const notas = [4, 6, 7, 9];

const hayAprobados = notas.some(nota => nota >= 6);

console.log(hayAprobados);

7️⃣ every() — ¿Todos cumplen?

Devuelve true solamente si todos los elementos cumplen la condición. 

const notas = [7, 8, 9, 10];

const todosAprobados = notas.every(nota => nota >= 6);

console.log(todosAprobados);

8️⃣ sort() — Ordenar arrays

Para ordenar números correctamente debemos proporcionar una función de comparación. 

const numeros = [30, 5, 100, 20, 8];

const ascendente = [...numeros].sort((a, b) => a - b);
const descendente = [...numeros].sort((a, b) => b - a);

console.log("Original:", numeros);
console.log("Ascendente:", ascendente);
console.log("Descendente:", descendente);
⚠️ Cuidado con sort()

sort() modifica el array sobre el que se ejecuta. Por eso usamos [...numeros] para crear una copia antes de ordenar.

Además, sin una función de comparación, JavaScript puede ordenar números como texto.

9️⃣ includes() — Comprobar si existe un valor

includes() devuelve true o false según el array contenga el valor indicado. 

const materias = [
  "Matemática",
  "Lengua",
  "Historia",
  "Programación"
];

console.log(materias.includes("Programación"));
console.log(materias.includes("Física"));

🔟 slice() — Copiar una parte del array

slice() devuelve una parte del array sin modificar el original. 

const numeros = [10, 20, 30, 40, 50];

const parte = numeros.slice(1, 4);

console.log(parte);
console.log(numeros);

const resultado = alumnos
  .filter(alumno => alumno.nota >= 6)
  .map(alumno => ({
    nombre: alumno.nombre,

console.log(resultado);

);

console.log(nombres);

2️⃣1️⃣ Crear estadísticas con reduce()

reduce() también puede utilizarse para construir objetos con estadísticas. 

const notas = [4, 7, 8, 10, 5, 9];

const estadisticas = notas.reduce(
  (resultado, nota) => {
    resultado.total++;

    if (nota >= 6) {
      resultado.aprobados++;
    } else {
      resultado.desaprobados++;
    }

    return resultado;
  },
  {
    total: 0,
    aprobados: 0,
    desaprobados: 0
  }
);

console.log(estadisticas);

2️⃣2️⃣ Agrupar información

Podemos utilizar reduce() para organizar elementos según una categoría. 

const alumnos = [
  { nombre: "Ana", curso: "5A" },
  { nombre: "Juan", curso: "5B" },
  { nombre: "Lucía", curso: "5A" },
  { nombre: "Pedro", curso: "5B" }
];

const grupos = alumnos.reduce(
  (resultado, alumno) => {
    if (!resultado[alumno.curso]) {
      resultado[alumno.curso] = [];
    }

    resultado[alumno.curso].push(alumno);

    return resultado;
  },
  {}
);

console.log(grupos);

2️⃣3️⃣ Diferencia entre map(), filter() y reduce()

  • map() → transforma cada elemento.
  • filter() → selecciona elementos.
  • find() → encuentra el primer elemento.
  • findIndex() → encuentra la posición.
  • reduce() → obtiene un resultado acumulado.
  • some() → comprueba si alguno cumple.
  • every() → comprueba si todos cumplen.
  • sort() → ordena el array.
  • includes() → comprueba si existe un valor.
  • slice() → obtiene una copia de una parte.

🔍 ¿Qué método debo elegir?

Antes de programar, preguntate qué resultado necesitás:

  • ¿Quiero cambiar cada elemento? → map()
  • ¿Quiero quedarme con algunos? → filter()
  • ¿Quiero encontrar uno? → find()
  • ¿Quiero saber dónde está? → findIndex()
  • ¿Quiero sumar o acumular? → reduce()
  • ¿Quiero saber si alguno cumple? → some()
  • ¿Quiero comprobar que todos cumplen? → every()
  • ¿Quiero ordenar? → sort()
  • ¿Quiero comprobar si existe? → includes()

Strings y métodos de texto

Los strings representan textos. JavaScript ofrece numerosos métodos para consultar, transformar, buscar, separar y construir cadenas. Estos métodos son fundamentales para formularios, nombres de usuarios, mensajes, validaciones y aplicaciones web.

🎯 Objetivos

  • Comprender qué es un string y cómo se trabaja con texto.
  • Obtener la longitud de una cadena.
  • Convertir texto a mayúsculas y minúsculas.
  • Buscar texto y comprobar si existe.
  • Extraer partes de una cadena.
  • Eliminar espacios innecesarios.
  • Reemplazar y dividir texto.
  • Combinar métodos para resolver problemas reales.

1️⃣ ¿Qué es un String?

Un string es una cadena de caracteres. Puede escribirse utilizando comillas dobles, comillas simples o backticks. 

const nombre = "Ana";
const curso = '5° A';
const mensaje = `Bienvenida ${nombre}`;

console.log(nombre);
console.log(curso);
console.log(mensaje);

2️⃣ length — Saber cuántos caracteres tiene

La propiedad length devuelve la cantidad de caracteres de un string. 

const texto = "JavaScript";

console.log(texto.length);
💡 Importante

length es una propiedad, no un método. Por eso se escribe texto.length y no texto.length().

3️⃣ toUpperCase() — Convertir a mayúsculas

Convierte todos los caracteres posibles del texto a mayúsculas. 

const nombre = "Juan Pérez";

console.log(nombre.toUpperCase());

4️⃣ toLowerCase() — Convertir a minúsculas

Convierte el texto a minúsculas. Es muy útil para realizar comparaciones sin importar cómo escribió el usuario. 

const respuesta = "SI";

if (respuesta.toLowerCase() === "si") {
  console.log("Respuesta afirmativa");
}

5️⃣ trim() — Eliminar espacios de los extremos

trim() elimina espacios al principio y al final del string. Es especialmente útil para datos ingresados en formularios. 

const nombre = "   Martín   ";

const limpio = nombre.trim();

console.log(limpio);

6️⃣ includes() — Comprobar si existe un texto

Devuelve true si encuentra el texto buscado y false si no lo encuentra. 

const mensaje = "Aprendiendo JavaScript";

console.log(mensaje.includes("JavaScript"));
console.log(mensaje.includes("Python"));

7️⃣ startsWith() — Comprobar cómo comienza

Comprueba si un string comienza con un determinado texto. 

const codigo = "JS-2026";

console.log(codigo.startsWith("JS"));
console.log(codigo.startsWith("PY"));

8️⃣ endsWith() — Comprobar cómo termina

Comprueba si el string termina con un determinado texto. 

const archivo = "actividad.html";

console.log(archivo.endsWith(".html"));
console.log(archivo.endsWith(".pdf"));

9️⃣ indexOf() — Buscar la posición

Devuelve la posición donde aparece por primera vez un texto. Si no lo encuentra, devuelve -1. 

const texto = "JavaScript es un lenguaje";

console.log(texto.indexOf("JavaScript"));
console.log(texto.indexOf("lenguaje"));
console.log(texto.indexOf("Python"));

🔟 lastIndexOf() — Buscar desde el final

Devuelve la posición de la última aparición de un texto. 

const texto = "JavaScript es genial y JavaScript es útil";

console.log(texto.lastIndexOf("JavaScript"));

1️⃣1️⃣ charAt() — Obtener un carácter

Permite obtener el carácter que se encuentra en una posición determinada. 

const palabra = "Hola";

console.log(palabra.charAt(0));
console.log(palabra.charAt(1));
console.log(palabra.charAt(3));

1️⃣2️⃣ Acceder mediante índices

También podemos acceder directamente a un carácter utilizando corchetes. 

const palabra = "Código";

console.log(palabra[0]);
console.log(palabra[2]);
console.log(palabra[5]);

1️⃣3️⃣ slice() — Extraer una parte del texto

slice() permite obtener una sección de un string sin modificar el original. 

const texto = "JavaScript";

const parte1 = texto.slice(0, 4);

Scope: alcance de las variables

El scope o alcance determina desde qué parte del programa podemos acceder a una variable. Comprenderlo ayuda a evitar errores, organizar el código y construir programas más fáciles de mantener.

🎯 Objetivos de la clase

  • Comprender qué significa scope.
  • Diferenciar alcance global, de función y de bloque.
  • Comprender el comportamiento de let, const y var.
  • Entender por qué una variable puede existir en un lugar y no en otro.
  • Evitar variables globales innecesarias.
  • Relacionar scope con funciones, eventos y aplicaciones web.

1️⃣ ¿Qué significa Scope?

Scope significa alcance. Indica la zona del programa en la que una variable puede ser utilizada.

Podemos imaginar cada bloque o función como una habitación. Una variable creada dentro de una habitación puede no estar disponible fuera de ella. 

const nombre = "Ana";

if (true) {
  const mensaje = "Hola";

  console.log(nombre);  // funciona
  console.log(mensaje); // funciona
}

console.log(nombre);    // funciona
// console.log(mensaje); // ❌ no existe aquí

2️⃣ Scope global

Una variable declarada fuera de funciones y bloques puede estar disponible desde diferentes partes del programa, según el contexto.

Aunque es posible utilizar variables globales, conviene evitar crear muchas porque diferentes partes del programa pueden depender de ellas y modificar su estado. 

const curso = "JavaScript";

function mostrarCurso() {
  console.log(curso);
}

mostrarCurso();
console.log(curso);

3️⃣ Scope de función

Una variable declarada dentro de una función pertenece al alcance de esa función. Desde fuera no podemos acceder directamente a ella. 

function calcular() {
  const resultado = 20 + 10;

  console.log(resultado);
}

calcular();

// ❌ resultado no existe fuera de calcular()
// console.log(resultado);

4️⃣ Scope de bloque

let y const respetan el alcance de un bloque delimitado por llaves { }. Esto aparece en if, for, while y otros bloques. 

if (true) {
  let edad = 15;
  const mensaje = "Hola";

  console.log(edad);
  console.log(mensaje);
}

// ❌ No están disponibles aquí
// console.log(edad);
// console.log(mensaje);

5️⃣ let, const y var

  • const: preferido cuando no necesitamos reasignar la variable.
  • let: utilizado cuando necesitamos cambiar su valor.
  • var: forma antigua de declarar variables; puede tener un comportamiento de alcance diferente y se recomienda evitarlo en código moderno.
const nombre = "Ana";

let contador = 0;
contador++;

console.log(nombre);
console.log(contador);

6️⃣ Scope dentro de un bucle

Las variables declaradas con let dentro del for pertenecen al bloque del bucle. 

for (let i = 1; i <= 3; i++) {
  console.log("Vuelta:", i);
}

// ❌ i no existe aquí
// console.log(i);

7️⃣ Scope y funciones anidadas

Una función interna puede acceder a variables disponibles en los ámbitos exteriores. Este comportamiento será muy importante cuando trabajemos con funciones, eventos y callbacks. 

function exterior() {
  const mensaje = "Hola";

  function interior() {
    console.log(mensaje);
  }

  interior();
}

exterior();
💡 Idea clave

El código interior puede acceder a variables de ámbitos exteriores disponibles para él, pero una variable creada en un ámbito interno no aparece mágicamente en el ámbito exterior.

8️⃣ ¿Por qué es importante el Scope?

  • Evita conflictos entre variables.
  • Reduce dependencias innecesarias.
  • Facilita encontrar errores.
  • Permite organizar programas grandes.
  • Ayuda a escribir funciones independientes.
  • Es fundamental para trabajar con eventos y formularios.

⚠️ Error frecuente

Crear muchas variables globales porque parece más sencillo al principio. En proyectos grandes esto puede producir nombres repetidos, modificaciones inesperadas y código difícil de mantener.

  • Función: variables disponibles dentro de una función.

Eventos en JavaScript

Los eventos permiten que JavaScript responda a las acciones del usuario y a situaciones que ocurren en el navegador.

🎯 Objetivos

  • Comprender qué es un evento.
  • Utilizar addEventListener().
  • Trabajar con eventos de mouse, teclado y formularios.
  • Comprender el objeto event.
  • Usar preventDefault().
  • Conocer propagación y delegación de eventos.
  • Construir interfaces interactivas.

1️⃣ ¿Qué es un evento?

Un evento es algo que sucede y que JavaScript puede detectar: un clic, una tecla, un cambio en un campo, el envío de un formulario, el movimiento del mouse o la carga de la página.

2️⃣ addEventListener()

addEventListener() conecta un elemento con una función que se ejecutará cuando ocurra determinado evento. 

const boton = document.querySelector("#boton");

boton.addEventListener("click", () => {
  console.log("Hiciste clic");
});

3️⃣ Eventos de mouse

  • click → clic.
  • dblclick → doble clic.
  • mouseenter → entra el mouse.
  • mouseleave → sale el mouse.
  • mousedown → se presiona un botón del mouse.
  • mouseup → se suelta el botón.
const tarjeta = document.querySelector("#tarjeta");

tarjeta.addEventListener("mouseenter", () => {
  tarjeta.classList.add("destacada");
});

tarjeta.addEventListener("mouseleave", () => {
  tarjeta.classList.remove("destacada");
});

4️⃣ Eventos de teclado

  • keydown → se presiona una tecla.
  • keyup → se libera una tecla.
document.addEventListener("keydown", evento => {
  console.log("Tecla:", evento.key);
});

5️⃣ El objeto event

La función que responde a un evento puede recibir un objeto con información sobre lo sucedido. 

const boton = document.querySelector("#boton");

boton.addEventListener("click", evento => {
  console.log("Elemento:", evento.target);
  console.log("Tipo:", evento.type);
});

6️⃣ input y change

input permite reaccionar mientras el usuario modifica un campo. change suele utilizarse cuando se confirma un cambio en el control. 

const nombre = document.querySelector("#nombre");

nombre.addEventListener("input", evento => {
  console.log("Valor actual:", evento.target.value);
});

7️⃣ submit y preventDefault()

Los formularios tienen un comportamiento predeterminado. Si queremos procesarlos con JavaScript antes de enviarlos, podemos utilizar preventDefault(). 

const formulario = document.querySelector("#formulario");

formulario.addEventListener("submit", evento => {
  evento.preventDefault();

  console.log("Formulario procesado por JavaScript");
});

8️⃣ Contador de clics

let contador = 0;

const boton = document.querySelector("#boton");
const resultado = document.querySelector("#resultado");

boton.addEventListener("click", () => {
  contador++;

  resultado.textContent =
    `Clics: ${contador}`;
});

9️⃣ Propagación de eventos

Los eventos pueden propagarse entre elementos relacionados. Para entender interfaces más grandes es importante conocer target y currentTarget. 

const contenedor = document.querySelector("#contenedor");

contenedor.addEventListener("click", evento => {
  console.log("Elemento que originó el evento:", evento.target);
  console.log("Elemento que escucha:", evento.currentTarget);
});

🔟 Delegación de eventos

En lugar de colocar un listener individual en cada elemento de una lista, podemos escuchar el evento desde un contenedor y utilizar event.target. Esto resulta especialmente útil cuando los elementos se crean dinámicamente. 

const lista = document.querySelector("#lista");

lista.addEventListener("click", evento => {
  if (evento.target.matches("button")) {
    console.log(
      "Botón seleccionado:",
      evento.target.textContent
    );
  }
});

1️⃣1️⃣ Cargar la página

Podemos ejecutar código cuando el documento ya fue cargado mediante DOMContentLoaded. 

document.addEventListener(
  "DOMContentLoaded",
  () => {
    console.log("DOM listo");
  }
);
⚠️ Error frecuente

No confundas registrar un evento con ejecutarlo inmediatamente. En addEventListener("click", funcion) se entrega la función para que el navegador la ejecute cuando ocurra el evento.

Formularios: recibir, validar y procesar datos

Los formularios permiten que una aplicación reciba información del usuario. HTML define la estructura y las restricciones básicas; JavaScript puede leer, validar, procesar y mostrar esos datos sin recargar la página.

🎯 Objetivos

  • Identificar los controles principales de un formulario.
  • Leer valores con value.
  • Procesar el evento submit.
  • Evitar el envío automático cuando sea necesario.
  • Validar datos.
  • Mostrar mensajes de error.
  • Trabajar con checkbox, radio y select.
  • Preparar datos para guardarlos en LocalStorage o enviarlos a un servidor.

1️⃣ Estructura básica

Un formulario utiliza <form> y distintos controles como input, select, textarea y botones. 

<form id="formulario">
  <label for="nombre">Nombre</label>
  <input
    id="nombre"
    name="nombre"
    type="text"
    required
  />

  <button type="submit">
    Guardar
  </button>
</form>

2️⃣ Leer un input

const nombre = document.querySelector("#nombre");

console.log(nombre.value);

3️⃣ trim(): limpiar datos

Los datos escritos por una persona pueden contener espacios innecesarios. trim() permite limpiar los extremos. 

const valor = nombre.value.trim();

if (valor === "") {
  console.log("Debe ingresar un nombre");
}

4️⃣ Procesar submit

const formulario =
  document.querySelector("#formulario");

  evento.preventDefault();

  const nombre =
    document.querySelector("#nombre").value.trim();

<input
  type="number"
  name="edad"

LocalStorage: guardar datos en el navegador

LocalStorage permite guardar pequeños datos en el navegador para que permanezcan disponibles después de cerrar o recargar la página.

1️⃣ ¿Qué es LocalStorage?

Es un mecanismo de almacenamiento del navegador que trabaja con pares clave → valor.

Los valores almacenados se manejan como texto. Por eso, para guardar arrays u objetos necesitamos convertirlos a JSON.

  "nombre",
  "Ana"
);

2️⃣ Leer un dato

  localStorage.getItem("nombre");

console.log(nombre);

  console.log("No hay una ciudad guardada");
}

JSON y Fetch

JSON y Fetch permiten trabajar con datos externos y comunicar una página web con servidores y APIs. En esta clase vamos a pasar de trabajar solamente con datos locales a consumir información real.

🎯 Objetivos de la clase

  • Comprender qué es JSON y por qué se utiliza.
  • Diferenciar un objeto JavaScript de un texto JSON.
  • Convertir datos con JSON.stringify() y JSON.parse().
  • Comprender el funcionamiento de fetch().
  • Trabajar con respuestas HTTP y response.ok.
  • Usar async/await para escribir código asíncrono más claro.
  • Enviar información a una API mediante POST.
  • Detectar y manejar errores de red, HTTP y de datos.
  • Mostrar datos obtenidos de una API dentro del DOM.

1️⃣ ¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar y transportar información de manera estructurada.

Aunque su sintaxis se parece a la de los objetos JavaScript, JSON es texto. Esto es importante porque los servidores normalmente envían y reciben datos en este formato. 

{
  "nombre": "Sofía",
  "edad": 14,
  "puntos": 85,
  "activo": true
}
💡 Recordá

En JSON las propiedades se escriben entre comillas dobles y no se utilizan funciones, comentarios ni valores como undefined.

2️⃣ Objeto JavaScript vs JSON

Un objeto JavaScript puede escribirse así:

const alumno = {
  nombre: "Sofía",
  edad: 14,
  puntos: 85
};

console.log(alumno.nombre);

El mismo dato representado como JSON es un texto: 

const textoJSON = '{"nombre":"Sofía","edad":14,"puntos":85}';

console.log(typeof textoJSON); // string

3️⃣ JSON.stringify() — Objeto → JSON

JSON.stringify() convierte un objeto o array de JavaScript en una cadena de texto JSON. 

const alumno = {
  nombre: "Sofía",
  edad: 14,
  puntos: 85
};

const textoJSON = JSON.stringify(alumno);

console.log(textoJSON);
console.log(typeof textoJSON);

4️⃣ JSON.parse() — JSON → Objeto

JSON.parse() realiza el proceso contrario: recibe texto JSON válido y lo convierte en un valor JavaScript. 

const textoJSON = '{"nombre":"Sofía","edad":14,"puntos":85}';

const alumno = JSON.parse(textoJSON);

console.log(alumno);
console.log(alumno.nombre);
console.log(typeof alumno);

5️⃣ JSON con arrays

JSON también permite representar listas de datos y estructuras más grandes. 

const alumnos = [
  { nombre: "Ana", nota: 9 },
  { nombre: "Juan", nota: 6 },
  { nombre: "Lucía", nota: 10 }
];

const datos = JSON.stringify(alumnos);
const recuperados = JSON.parse(datos);

console.log(recuperados);
console.log(recuperados[0].nombre);

6️⃣ ¿Qué es Fetch?

fetch() permite realizar solicitudes HTTP desde JavaScript. Se utiliza para obtener información de un servidor, enviar datos o comunicarse con una API.

Una petición es asíncrona: el navegador puede continuar trabajando mientras espera la respuesta. 

fetch("https://jsonplaceholder.typicode.com/users")
  .then(respuesta => respuesta.json())
  .then(datos => {
    console.log(datos);
  })
  .catch(error => {
    console.error("Error:", error);
  });

7️⃣ Fetch con async/await

async/await permite escribir código asíncrono con una estructura más fácil de leer. 

async function cargarUsuarios() {
  const respuesta = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  const usuarios = await respuesta.json();

  console.log(usuarios);
}

cargarUsuarios();

8️⃣ response.ok — Comprobar la respuesta

Una petición puede completarse técnicamente aunque el servidor responda con un estado HTTP de error. Por eso conviene comprobar response.ok antes de procesar los datos. 

async function cargarDatos() {
  const respuesta = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  if (!respuesta.ok) {
    throw new Error(
      `Error HTTP: ${respuesta.status} ${respuesta.statusText}`
    );
  }

  const datos = await respuesta.json();
  console.log(datos);
}

cargarDatos();

9️⃣ Estados HTTP importantes

  • 200: solicitud correcta.
  • 201: recurso creado correctamente.
  • 400: solicitud incorrecta.
  • 401: falta autenticación válida.
  • 403: acceso prohibido.
  • 404: recurso no encontrado.
  • 500: error interno del servidor.

1️⃣7️⃣ Validar los datos recibidos

No debemos asumir que una API siempre devuelve exactamente lo que esperamos. Podemos comprobar que el resultado tenga la estructura necesaria antes de utilizarlo. 

async function cargarUsuarios() {
  const respuesta = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  if (!respuesta.ok) {
    throw new Error(`HTTP ${respuesta.status}`);
  }

  const datos = await respuesta.json();

  if (!Array.isArray(datos)) {
    throw new Error("La API no devolvió una lista de usuarios");
  }

  for (const usuario of datos) {
    if (!usuario.name || !usuario.email) {
      console.warn("Usuario con datos incompletos:", usuario);
      continue;
    }

    console.log(usuario.name, usuario.email);
  }
}

cargarUsuarios().catch(error => {
  console.error("Error:", error.message);
});

1️⃣8️⃣ Manejo completo de errores

Una aplicación más robusta combina try, catch, response.ok y validaciones. 

async function cargarDatos() {
  const mensaje = document.querySelector("#mensaje");

  try {
    mensaje.textContent = "Cargando...";

    const respuesta = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    if (!respuesta.ok) {
      throw new Error(
        `El servidor respondió con HTTP ${respuesta.status}`
      );
    }

    const datos = await respuesta.json();

    if (!Array.isArray(datos)) {
      throw new Error("Formato de datos inesperado");
    }

    mensaje.textContent = `Se cargaron ${datos.length} usuarios.`;
  } catch (error) {
    mensaje.textContent = "No fue posible cargar los datos.";
    console.error(error);
  }
}

cargarDatos();

🧠 Diferencia entre errores de Fetch

  • Error de red: la solicitud no pudo completarse, por ejemplo por falta de conexión o problemas de acceso.
  • Error HTTP: el servidor respondió, pero indicó un estado como 404 o 500. Se detecta con response.ok o response.status.
  • Error de datos: la respuesta llegó, pero no tiene el formato esperado o no se puede convertir correctamente.

Errores y depuración

Un buen programador no solamente escribe código: también sabe encontrar, interpretar, corregir y prevenir errores. En esta clase vamos a aprender a utilizar las herramientas del navegador para detectar problemas de sintaxis, ejecución, lógica, datos y red.

🎯 Objetivos de la clase

  • Reconocer los principales tipos de errores.
  • Interpretar mensajes de la consola.
  • Utilizar try, catch y finally.
  • Lanzar errores personalizados con throw.
  • Validar datos antes de utilizarlos.
  • Detectar errores relacionados con JSON y Fetch.
  • Utilizar herramientas de DevTools y breakpoints.
  • Desarrollar una estrategia ordenada para depurar programas.

1️⃣ ¿Qué es un error?

Un error ocurre cuando el programa no puede realizar correctamente una instrucción o cuando el resultado obtenido no es el esperado.

Algunos errores impiden que el programa comience. Otros aparecen durante la ejecución y también existen errores de lógica donde el programa funciona, pero produce un resultado incorrecto.

2️⃣ Error de sintaxis

Se produce cuando el código no respeta las reglas de escritura de JavaScript. El navegador normalmente señala dónde encontró el problema. 

// Falta cerrar el paréntesis
console.log("Hola";

// Versión correcta
console.log("Hola");

3️⃣ ReferenceError

Aparece cuando intentamos utilizar una variable que no existe en el contexto actual. 

const nombre = "Ana";

console.log(nombre);
console.log(edad); // ReferenceError

4️⃣ TypeError

Ocurre cuando intentamos realizar una operación que no es válida para el tipo de dato que estamos utilizando. 

const alumno = null;

// TypeError: no podemos acceder a nombre desde null
console.log(alumno.nombre);

5️⃣ RangeError

Se produce cuando un valor está fuera del rango permitido por una operación. 

const numero = 10;

try {
  console.log(numero.toFixed(101));
} catch (error) {
  console.error("RangeError:", error.message);
}

6️⃣ Error de lógica

Es especialmente importante porque el programa puede ejecutarse sin mostrar un error en rojo, pero entregar un resultado incorrecto. 

const precio = 1000;
const cantidad = 3;

// Error lógico: debería multiplicar, no sumar.
const total = precio + cantidad;

console.log(total);
🧠 Pregunta clave

Si el navegador no muestra un error, eso no significa que el programa esté necesariamente bien. Siempre debemos comprobar que el resultado sea correcto.

7️⃣ try / catch

try contiene el código que puede producir un error. Si ocurre un error, catch permite capturarlo y responder de una manera controlada. 

try {
  const numero = Number("abc");

  if (Number.isNaN(numero)) {
    throw new Error("El valor no es un número válido");
  }

  console.log(numero);
} catch (error) {
  console.error("Ocurrió un error:", error.message);
}

8️⃣ finally

finally se ejecuta tanto si ocurre un error como si la operación termina correctamente. Es útil para indicar que una tarea finalizó o para limpiar recursos. 

try {
  console.log("Procesando datos...");
} catch (error) {
  console.error(error.message);
} finally {
  console.log("Proceso terminado");
}

9️⃣ throw — Crear nuestros propios errores

Podemos utilizar throw para detener una operación y generar un error cuando una condición no es válida. 

function validarEdad(edad) {
  if (!Number.isFinite(edad)) {
    throw new Error("La edad debe ser un número");
  }

  if (edad < 0) {
    throw new Error("La edad no puede ser negativa");
  }

  return true;
}

try {
  validarEdad(-5);
} catch (error) {
  console.error(error.message);
}

🔟 Validar datos antes de procesarlos

Muchas fallas pueden evitarse comprobando los datos antes de utilizarlos. 

function calcularPromedio(notas) {
  if (!Array.isArray(notas)) {
    throw new Error("Se esperaba un array de notas");
  }

  if (notas.length === 0) {
    throw new Error("No hay notas para calcular");
  }

  if (!notas.every(nota => Number.isFinite(nota))) {
    throw new Error("Todas las notas deben ser números");
  }

  const suma = notas.reduce(
    (total, nota) => total + nota,
    0
  );

  return suma / notas.length;
}

try {
  console.log(calcularPromedio([8, 9, 10]));
} catch (error) {
  console.error(error.message);
}

1️⃣1️⃣ Errores con JSON.parse()

Si el texto no tiene un formato JSON válido, JSON.parse() puede producir un error. Por eso es recomendable utilizarlo dentro de un try/catch cuando los datos pueden ser externos o desconocidos. 

const texto = '{nombre: "Ana"}';

try {
  const objeto = JSON.parse(texto);
  console.log(objeto);
} catch (error) {
  console.error("JSON inválido:", error.message);
}

1️⃣2️⃣ Errores con Fetch

Con fetch() debemos diferenciar un problema de red de una respuesta HTTP con estado de error. 

async function cargarDatos() {
  try {
    const respuesta = await fetch(
      "https://jsonplaceholder.typicode.com/usuarios-inexistentes"
    );

    if (!respuesta.ok) {
      throw new Error(
        `Error HTTP ${respuesta.status}: ${respuesta.statusText}`
      );
    }

    const datos = await respuesta.json();
    console.log(datos);
  } catch (error) {
    console.error("No se pudieron cargar los datos:", error.message);
  }
}

cargarDatos();
⚠️ Error frecuente con Fetch

fetch() no considera automáticamente un estado HTTP como 404 o 500 una excepción. Por eso debemos comprobar response.ok y, cuando sea necesario, lanzar nuestro propio error con throw.

1️⃣3️⃣ console.log(), console.error() y console.warn()

La consola es una de las herramientas principales para conocer qué está haciendo nuestro programa. 

const usuario = {
  nombre: "Ana",
  edad: 16
};

console.log("Usuario:", usuario);
console.warn("Esta es una advertencia");
console.error("Este es un mensaje de error");
console.table([usuario]);

1️⃣4️⃣ console.table()

Cuando trabajamos con arrays de objetos, console.table() permite visualizar los datos en forma de tabla y facilita el análisis. 

const alumnos = [
  { nombre: "Ana", nota: 9 },
  { nombre: "Juan", nota: 6 },
  { nombre: "Lucía", nota: 10 }
];

console.table(alumnos);

1️⃣5️⃣ Debugger

La instrucción debugger puede detener la ejecución cuando las herramientas de desarrollo del navegador están abiertas. Esto permite observar variables y seguir el programa paso a paso. 

function calcularTotal(precio, cantidad) {
  const subtotal = precio * cantidad;

  debugger;

  return subtotal;
}

console.log(calcularTotal(1500, 4));

1️⃣6️⃣ Breakpoints en DevTools

También podemos colocar un breakpoint haciendo clic sobre el número de línea dentro de las herramientas de desarrollo del navegador.

  1. Abrí las herramientas del navegador con F12.
  2. Ingresá en la pestaña Sources.
  3. Buscá el archivo JavaScript.
  4. Hacé clic sobre el número de línea.
  5. Ejecutá nuevamente el programa.
  6. Observá las variables y avanzá instrucción por instrucción.

1️⃣7️⃣ Estrategia para encontrar errores

1. ¿El código tiene un error de sintaxis?
             ↓
2. ¿La consola muestra algún mensaje?
             ↓
3. ¿Qué línea indica el error?
             ↓
4. ¿Qué valores tienen las variables?
             ↓
5. ¿La condición realmente se cumple?
             ↓
6. ¿El resultado coincide con lo esperado?
             ↓
7. Probar nuevamente después de corregir

1️⃣8️⃣ Ejemplo de depuración

El siguiente programa debería calcular el total de una compra. Buscá el error lógico antes de mirar la solución. 

const precio = 1500;
const cantidad = 4;
const descuento = 10;

const subtotal = precio + cantidad;
const montoDescuento = subtotal * descuento / 100;
const total = subtotal - montoDescuento;

console.log("Subtotal:", subtotal);
console.log("Descuento:", montoDescuento);
console.log("Total:", total);
🔎 Analizá

El problema está en el cálculo del subtotal. Si el precio es $1500 y se compran 4 unidades, debemos multiplicar precio por cantidad. 

const precio = 1500;
const cantidad = 4;
const descuento = 10;

const subtotal = precio * cantidad;
const montoDescuento = subtotal * descuento / 100;
const total = subtotal - montoDescuento;

console.log("Subtotal:", subtotal);
console.log("Descuento:", montoDescuento);
console.log("Total:", total);

1️⃣9️⃣ Errores de alcance (Scope)

Una variable declarada dentro de una función o bloque puede no estar disponible fuera de ese contexto. 

function calcular() {
  const resultado = 30;
  console.log(resultado);
}

calcular();

// Error: resultado no existe fuera de la función.
// console.log(resultado);

2️⃣0️⃣ Errores frecuentes que debemos evitar

  • Escribir mal el nombre de una variable.
  • Usar una variable antes de declararla.
  • Confundir = con ===.
  • Olvidar aumentar un contador en un bucle.
  • Intentar acceder a una propiedad de null o undefined.
  • No validar datos recibidos de formularios o APIs.
  • No comprobar response.ok en Fetch.
  • Intentar hacer JSON.parse() sobre JSON inválido.
  • Modificar el DOM sin comprobar que el elemento exista.
  • Corregir un error sin volver a probar el programa.
